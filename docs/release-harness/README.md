# FABLEBREAKER Ecosystem Release Harness

This harness turns `ItsNotAILABS/FABLEBREAKER` into the benchmark/proof feeder for the NOVA model-family root.

## Purpose

FABLEBREAKER feeds proof-before-speed benchmark contracts, evidence schemas, evaluation receipts, and claim-boundary enforcement into NOVA.

## Release package

- `docs/release-harness/release-packages/v1.0.0/RELEASE.md`
- `docs/release-harness/release-packages/v1.0.0/release-manifest.json`

## Model

- FABLEBREAKER Benchmark Model: claim testing, proof posture, reproducibility, and benchmark release boundaries.

## Promotion gates

1. CI success.
2. Operator approval.
3. Reproducibility evidence for any benchmark claim.
4. Clear separation between measured result and marketing language.

## Boundaries

- proof before speed
- no unverified leaderboard claim
- no universal benchmark truth claim
- no unsupported state-of-the-art claim
- operator approval required
